# 关卡数值期望

记录日期：2026-08-02

适用范围：挑战1~9、主线西部荒野WF1~3。

## 评测口径

- 主验收指标使用固定策略AI的`averageBestPassRate`，即三个average操作档在各自最佳合法构筑上的通过率平均值。
- 每个目标同时对战士T`warrior_t`和熊T`druid_bear_t`生效。
- 两职业通过率差优先控制在10个百分点以内，最大不超过15个百分点。
- 不以`overallBestPassRate`代替普通操作档结果；skilled和expert档用于确认合理操作下仍存在通关路径。

## 操作敏感性期望

- 使用现有`average2-800ms-10pct`作为不太熟练玩家代理，使用`skilled2-300ms-5pct`作为熟练玩家参照。
- 优先让不熟练代理通过率比熟练参照低10~20个百分点，同时仍保留至少10%通过率。
- 该项是次级目标；不得为了制造操作差而让主指标离开逐关目标区间，或让任一职业形成机制性0%通过率。

## 允许的调平手段

按以下优先级使用，每关优先只采用前部手段：

1. 替换1个同章节首次出现的敌人。
2. 仍不达标时最多替换第2个敌人。
3. 调整敌人`openingCastSkillNum`，改变开场施法队列位置。
4. 调整`openingRecoveryRemainingMs`，错开危险读条和敌人发呆时间。
5. 调整敌人网格位置，控制玩家范围技能的覆盖数量。
6. 如果高生命机制怪导致战斗拖长且无法平衡，可将该敌人的开场生命和最大生命设为基础值的50%，并在`nameOverride`前添加“负伤的”。

## 章节边界

- 挑战1~3只使用第一章喧鸣深窟首次出现的敌人作为替换候选。
- 挑战4~6只使用第二章西部荒野首次出现的敌人作为替换候选。
- 挑战7~9只使用第三章祖阿曼首次出现的敌人作为替换候选。
- WF1~3只能使用西部荒野中不晚于当前关卡首次登场的敌人，禁止提前引入后续主线怪物。

## 禁止项与回退条件

- 不修改战士T或熊T的技能、天赋、资源和AI职业策略来迁就本轮关卡目标。
- 不修改全局敌人定义、敌人技能数值、关卡词缀或特殊规则。
- 不批量重建或覆盖`public/designer-data/`；只允许按稳定ID定点修改已批准的关卡行。
- 如果替换两名敌人、时序和站位仍无法让两职业同时进入目标区间，应记录结构性原因并回退最近一次无效调整，不叠加隐藏职业补偿。

## 最终交付

- 逐关记录原编成、新编成、施法队列、发呆时间、站位及负伤变体。
- 同时记录两职业的average、skilled、expert通过率、难度评级、职业差和操作敏感性差值。
- 先运行quick筛选，再运行normal确认；挑战3、5、6、8、9至少进行一次更高样本复核。
- 最终报告需明确列出未达到目标的关卡及不继续调整的原因。
