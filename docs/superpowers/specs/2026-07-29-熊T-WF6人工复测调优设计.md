# 熊T WF6 人工复测数值调整设计

## 目标

回调上一轮偏强的通用防御数值，强化指定天赋和沉睡者之怒的职业循环，并将演示存档推进到全关卡、全职业可用状态，以便人工测试与WF6自动评测同步进行。

## 主动技能

- 铁鬃恢复为消耗20怒；默认每层20%物理减伤，最多3层。
- 树皮术恢复为10秒30%全伤害减伤。
- 沉睡者之怒与生存本能交换解锁关卡：沉睡者之怒在WF-5解锁，生存本能在ZA-3解锁。挑战4~6的累计快照因此包含沉睡者之怒而不是生存本能；挑战7~9仍累计包含两者。
- 沉睡者之怒保留20怒消耗、25%全伤害减伤、承伤反击和相关队伍天赋，持续时间改为10秒；成功释放时获得25怒，并增加25%最大生命值。
- 所有熊T临时最大生命值效果在获得和结束时保持当前生命百分比不变。

## 被动天赋

- 野性专注：裂伤额外获得7怒，痛击不受影响。
- 野性印记：熊T和队伍造成伤害提高20%，不增加独立仇恨倍率。
- 铁棘：每层铁鬃使队伍伤害提高15%，默认3层上限45%。
- 树皮净化：保留树皮术结束时驱散所有可驱散玩家减益，并额外治疗结束时当前最大生命值的10%。该治疗使用标准治疗倍率并受禁疗影响。
- 回春羁绊：消耗1点天赋点，效果不变。
- 水火不侵：不改变铁鬃最大层数；每层保留20%物理减伤并增加10%魔法减伤，最多3层。

## 数据与运行时边界

- 所有可配置数值、描述、解锁提示和构筑点数写入`player_build.xlsx`。
- 主线和挑战累计技能快照分别定点更新`stage_content.xlsx`和`challenge_stage_content.xlsx`。
- 使用稳定ID脚本定点修改已授权字段，不运行`generate:designer-data`或整表生成器。
- 运行时只实现策划表无法单独表达的行为：树皮结束治疗、沉睡者之怒怒气获取、临时最大生命值同步和水火不侵双类型减伤。

## 演示与评测

- 启动最新版Vite演示环境。
- 写入`littleTank.save.2.dev`演示存档：完成全部主线，记录所有挑战职业胜利，解锁当前全部职业和关卡，并保留合法默认构筑。
- 演示入口定位到可选择熊T进入WF6的地图状态，不绕过正常战前准备。
- 与人工测试同步运行熊T WF6完整预算固定/学习策略评测，输出相对上一版的通过率、生存、承伤、治疗/吸收、怒气、伤害和失败信号变化。

## 验证标准

- 策划表契约、运行时行为、最大生命值百分比保持、解锁快照和互斥构筑测试通过。
- `npm test`、`npm run lint`、`npm run build`、`npm run validate:designer-data`和`git diff --check`通过。
- WF6报告必须包含有效的单关熊T样本，不接受空筛选报告。
