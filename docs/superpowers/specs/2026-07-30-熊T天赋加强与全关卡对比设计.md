# 熊 T 天赋加强与全关卡双职业评测设计

日期：2026-07-30

## 目标

在当前最新版策划表基础上加强七项熊 T 被动天赋，修正未选中敌人血条的双框视觉，然后使用相同的完整预算评测熊 T 与战士 T 在挑战 1~9、WF1~6、ZA1~6 共 21 个关卡的表现，形成可复查的职业对比基线。

## 修改边界

- 允许定向修改 `public/designer-data/player_build.xlsx` 中本次涉及的熊 T 天赋定义与效果值。
- 不运行 `npm run generate:designer-data`，不整体重建或覆盖策划表目录。
- 同步更新读取这些策划值的运行时后备值、行为测试和维护脚本，避免策划表缺失时退回旧数值。
- UI 仅调整未选中敌人的威胁色内边框，不改变敌人血条尺寸、排布、选中框或威胁颜色。
- 不在本轮直接调整关卡、敌人或其他职业数值；完整评测完成后只记录结论与后续建议。

## 天赋规则

### 厚皮

- 数值维持常驻 `10%` 物理减伤。
- 天赋说明明确写出“与铁鬃提供的物理减伤线性叠加”。
- 计算时先将厚皮与当前铁鬃物理减伤相加并按现有上限封顶。例如三层铁鬃为 `60%`，加厚皮后为 `70%`。
- 树皮术、沉睡者之怒、敌我状态等其他减伤继续与上述结果乘法叠加。
- 没有铁鬃时，厚皮仍独立提供 `10%` 物理减伤；不影响魔法伤害。

### 其余六项

| 天赋 | 最终规则 |
| --- | --- |
| 熊威 | 所有熊 T 主动技能的额外仇恨倍率提高 `35%` |
| 自然鼓舞 | 队伍自动攻击间隔缩短 `25%`，不改变熊 T 自动攻击间隔 |
| 野性印记 | 熊 T 自身和队伍造成的伤害提高 `25%` |
| 断法本能 | 成功打断后获得 `15` 点怒气；失败或没有可打断读条时不获得怒气 |
| 巨熊活力 | 最大生命值提高 `30%`，继续使用现有按比例同步当前生命值的永久最大生命规则 |
| 兽群愈合 | 愈合释放时，队伍获得该次即时原始治疗量 `50%` 的治疗；愈合 HoT 的后续跳数不治疗队伍 |

野性印记不新增独立仇恨倍率。伤害与仇恨的既有公式关系保持不变，熊威仍是本组唯一直接提高熊 T 技能仇恨倍率的天赋。

## 数据与运行时

`player_build.xlsx` 继续作为策划数值来源。实现应定向更新七项天赋的描述和 `valueA`，并保持现有 `talentId`、解锁关卡、技能点、竞争组和图标不变。

运行时按现有 `talentLogicId` 消费数值：

- 厚皮与铁鬃在玩家物理承伤入口合并为一个加法减伤段，再与其他减伤段相乘。
- 熊威、自然鼓舞、野性印记和巨熊活力继续通过被动修正器解析策划值。
- 断法本能继续只在确认成功打断后发放怒气。
- 兽群愈合继续位于愈合即时施法处理器中，不能进入周期治疗 tick 处理路径。

维护脚本应只更新明确列出的行，并在缺少目标行时直接报错，防止静默写坏策划表。

## 敌人血条 UI

当前未选中敌人使用原始 `3px` 边框和一个向内偏移 `3px` 的伪元素边框，因此中间存在可见间隙。将伪元素贴到内容边缘，使额外 `3px` 内框与原始边框连续相接，形成视觉上连续的 `6px` 威胁色边框。

额外边框仍只向框内扩展，不占用相邻敌人血条空间，不改变点击区域，并继续使用绿、黄、红及锁定灰四种现有威胁色。

## 测试策略

采用测试先行：

1. 策划数据测试先断言七项最终描述与数值。
2. 运行时测试分别覆盖厚皮与 0~3 层铁鬃的线性叠加、魔法伤害不受厚皮影响、35% 仇恨、25% 自动攻击间隔、25% 双侧伤害、15 怒气、30% 最大生命和愈合即时/持续治疗边界。
3. UI 样式契约测试先断言未选中内框紧贴原始边框，再修改 CSS。
4. 完成后运行相关测试、完整测试、lint、build、策划表校验和 `git diff --check`。

## 完整评测

采用方案 A，使用 `full` 样本预算，评测范围为：

- `Challenge-1` 至 `Challenge-9`
- `WestFall-1` 至 `WestFall-6`
- `Zul'Aman-1` 至 `Zul'Aman-6`
- 职业：`warrior_t`、`druid_bear_t`

挑战和主线分别运行分析器，两个职业在每个关卡使用相同的构筑点数、解锁快照、构筑搜索上限、操作档位、随机种子规则和正式样本数。战士 T 也在当前版本重新运行，旧报告仅作为历史参照，不直接与新熊 T 样本混算。

每个“关卡 + 职业”至少记录：

- 人工难度评级
- 固定策略最佳通过率及 average、skilled、expert 档位结果
- 学习型 AI 最佳正式通过率与综合操作难度
- 最佳构筑标识及主动技能、被动天赋
- 主要失败信号，包括坦克承伤、队伍压力、敌方治疗、高危读条和仇恨失控

## 产物

生成一份 Markdown 对比报告和一份对应 JSON 原始记录，存放在 `reports/balance/`。Markdown 按挑战、WF、ZA 分组，以战士 T 为基准列出熊 T 的通过率差值、难度差和异常标记，并在结尾汇总：

- 熊 T 明显强于或弱于战士 T 的关卡
- 两职业难度相差超过一级的关卡
- 自动结果与人工评级明显不一致的关卡
- 更可能需要职业功能补全、AI 策略改进或单关调整的问题

评测允许最长约 8 小时。若个别完整分析在时限内未完成，保留已完成的原始产物，在报告中明确标记缺失样本，不使用快速样本冒充完整结果。

## 验收标准

- 七项天赋的策划表显示值、运行时行为和测试一致。
- 厚皮与三层铁鬃共同产生 `70%` 物理减伤，并与其他减伤乘法叠加。
- 兽群愈合只响应愈合即时治疗。
- 未选中敌人血条呈现连续、无间隙且不越界的加粗威胁边框。
- 21 个关卡均包含当前版本的熊 T 与战士 T 同口径结果，或在 8 小时上限内明确记录未完成项。
- 报告能够逐关比较成功率、操作难度、最佳构筑和主要失败原因。
