# 熊T资源循环与挑战平衡调整设计

## 目标

调整熊T前期怒气循环、若干被动天赋和生存联动，使技能消耗与怒气获取形成更明确的循环；随后重新平衡挑战1~3，使固定AI不同操作档位形成约40%~90%的区分度，并只允许高手参数下的学习型AI稳定超过95%。

## 主动技能数据

- 迎头痛击的怒气消耗由10降为0。
- 铁鬃的怒气消耗由35降为20。
- 狂暴回复的怒气消耗由35降为20。
- 裂伤成功释放的基础怒气获取由20降为15。
- 痛击成功释放的基础怒气获取由15降为5。

上述基础数值继续由`player_build.xlsx`的技能定义与主动技能效果读取，运行时不得重新写死。

## 被动天赋

### 野性专注

野性专注仍额外提供5怒，但只增强裂伤，不再增强痛击。

### 痛苦之怒

- 新增Tier 0天赋，消耗4点构筑点。
- 痛击成功释放后，按实际命中的存活敌人数结算额外怒气。
- 每命中一个目标获得2怒，单次最多额外获得10怒。
- 未命中目标时不获得额外怒气。
- 该怒气必须走统一熊T怒气事件，以便春风吹又生和禁怒状态正确处理。

### 铁鬃余韵

- 铁鬃结束后获得5秒10%物理减伤。
- 余韵与后来施放的新铁鬃作为两个独立减伤来源存在。
- 承伤计算时线性相加，并继续受现有总减伤上限约束。

### 破盾回响

- 只有选择破盾回响后，树皮术的有效怒气消耗才从0变为10。
- 怒气不足10点时树皮术不可释放，UI和运行时使用同一阻止原因。
- 成功释放树皮术时，除原有减伤外获得独立的5秒20点全伤害吸收盾。
- 只有这个树皮术护盾在持续时间结束前被伤害完全消耗，才返还20怒。
- 自然到期、被覆盖、其他来源护盾破碎均不得触发返怒。

### 林地守护者

熊T生命高于既有80%阈值时，队伍全伤害减伤由6%提高至25%。

### 巨熊绝境

- 每场战斗仍只触发一次。
- 受到致命伤害时，生命值保留为当前最大生命值的15%，最低为1。
- 同时施加10秒可驱散玩家减益“怒气枯竭”。
- 怒气枯竭存在时，所有熊T怒气获取事件均被阻止，包括技能基础获取、天赋奖励、打断奖励、护盾破碎奖励和主动技能直接回怒。
- 已有怒气不清空，技能仍可正常消耗现有怒气。
- 由于该状态可驱散，树皮净化等既有全量可驱散减益清除机制可以移除它。

### 春风吹又生

累计怒气治疗阈值由30提高至60，每跨过一个完整阈值仍治疗队伍5点；单次大额怒气可以跨越多个阈值。

## 数据与资产

- 在`player_build.xlsx`中定点维护技能、效果、天赋、状态和图标映射行。
- 新增痛苦之怒天赋图标和怒气枯竭状态图标，沿用现有熊T资源的SVG视觉语言。
- 当前工作区内`player_build.xlsx`存在人工改动；实现必须以当前文件为基线，只修改本规格涉及的单元格和新增行。
- 不运行`npm run generate:designer-data`或任何会批量覆盖`public/`的生成器。

## 运行时边界

- 所有熊T怒气获取必须收敛到统一事件入口，由该入口处理怒气枯竭、资源上限和春风吹又生累计值。
- 痛苦之怒在痛击目标集合确定后结算，不能根据棋盘总敌人数推算。
- 破盾回响护盾使用独立状态ID，吸收消费逻辑只允许该ID触发返怒。
- 铁鬃余韵继续使用独立玩家增益；伤害管线同时读取铁鬃主减伤与余韵增益，保证线性叠加。

## 挑战1~3平衡流程

1. 先完成数据和运行时行为测试，保持挑战表不动。
2. 对挑战1~3采集两职业固定AI各操作档位与学习型AI报告。
3. 优先调整挑战工作簿内的关卡开场、敌人生命覆写、布置和挑战专属词缀，不修改主线或全局敌人数据。
4. 固定AI目标为各职业、各关主要档位约40%~90%，并体现失误率、操作延迟和操作预算差异。
5. 学习型AI原则上只有高手模拟参数允许达到95%以上；普通参数不应普遍满通过。
6. 继续满足职业比较约束：无工具缺口、无明显强度溢出、同关难度不跨一档以上、三关平均最佳通过率差绝对值不超过15个百分点。

若某关因RD-6五技能快照或离散敌人机制无法同时满足所有范围，保留最接近且无职业硬性工具缺口的配置，并在交接文档记录具体冲突、测量结果和人工试玩重点。

## 测试与验收

- 策划表契约测试覆盖所有指定数值、新天赋、新状态和图标映射。
- 行为测试覆盖单体/五目标痛击回怒、野性专注仅增强裂伤、树皮术条件消耗、专属护盾破碎/到期、余韵叠加、巨熊绝境15%生命与全来源禁怒、可驱散边界和60怒治疗阈值。
- 完成挑战1~3 quick自动评测并保存报告。
- 完成挑战4~9默认熊T构筑烟测，防止新增Tier 0天赋破坏累计快照。
- 最终运行`npm test`、`npm run validate:designer-data`、`npm run lint`、`npm run build`和`git diff --check`。
