# 熊 T 图标统一与敌人框线优化设计

## 背景

熊 T 当前 53 个职业相关图标虽然已经具有独立资源，但与战士 T 的视觉语言仍不一致：图标内部存在方形描边、四角标记、底部横台，并大量使用浅色纯线条作为主体。UI 还额外叠加了主动技能战旗、被动天赋盾牌和职业纹样角标，图标槽自身也带有背景、边框、圆角与阴影，导致小尺寸图标出现多层框套框和填充边界不一致。

敌人血条方块的悬停框与选中动态框仍沿用旧的 3px 视觉权重，与此前加粗后的血条基础框线不匹配。

## 目标

1. 将熊 T 的 16 个主动技能、21 个被动天赋和 16 个状态图标统一为战士 T 的双色块面画风。
2. 移除图标内部多余装饰框、角线和底台，使主体成为第一视觉层级。
3. 从战斗、构筑、状态和教程 UI 中移除职业来源战旗、盾牌与纹样角标。
4. 移除技能、天赋和状态图标紧邻槽位的背景圆角矩形，同时保留稳定尺寸与必要的战斗信息覆盖层。
5. 保留状态的绿色、红色和金色语义边框，以继续区分增益、减益和团队状态。
6. 将敌人血条方块的橙黄悬停框和白色动态虚线框向内部加粗到现有视觉厚度的 2 倍，不改变敌人格位外部尺寸。

## 非目标

- 不重绘战士 T 图标。
- 不更改熊 T 技能、天赋、状态的策划映射和数值。
- 不删除状态来源元数据；只停止在 UI 中渲染职业来源角标。
- 不删除技能卡、天赋卡、状态说明卡等内容承载卡片的背景。
- 不改变正式玩家的新存档或解锁流程。

## 熊 T 图标视觉规范

### 画布与背景

- 继续使用 64x64 SVG 和当前唯一 `assetKey`，不改工作簿映射。
- 使用战士式深色双色渐变背景，允许按语义使用月光蓝、自然绿、怒气红、铁甲青等色组。
- 背景主体采用内缩圆角块面，透明四角由 SVG 自身控制。
- 不绘制外沿描边、内部方框、四角标记或底部横台。

### 主体造型

- 主体由 1 个实心主块面、深色粗描边和最多 1 个高亮辅形构成。
- 不使用大面积浅色纯线条作为核心图形；线条只用于必要的内部切分或动作方向。
- 主体占画布约 58% 至 76%，在 18px 状态尺寸下仍能识别主要轮廓。
- 同源技能与状态可以共享轮廓语义，但通过配色、辅形或构图偏移保持资源可区分。
- 生成结果增加 `data-icon-style="warrior-block"` 和 `data-icon-layer="core"` 标记，便于自动验证。

### 资产生成约束

- 更新现有定向脚本 `scripts/applyBearTIconPresentation.mjs`，只覆盖 53 个已授权熊 T SVG。
- 脚本不再写入 `player_build.xlsx`，因为映射已经正确且无需变化。
- 脚本执行前后校验目标文件数为 53，并确保不生成框线和底台层。
- 不运行任何整表或公共资源批量生成器。

## UI 图标呈现

### 职业来源角标

- `SkillBar` 不再渲染主动技能 `StatusSourceEmblem`。
- `PassiveTalentPanel` 的天赋本体和衍生状态不再渲染盾牌或熊抓来源角标。
- `StatusBadge` 在战斗、构筑预览、敌人框和状态面板中均不再渲染 `StatusSourceEmblem`。
- 状态对象中的 `sourceKind` 和 `sourceClassId` 保留，供逻辑、调试和未来展示使用。
- 删除教程中“主动技能战旗/被动天赋盾牌”的说明与示例；职业选择界面的剑、熊抓等职业纹样不受影响。

### 图标槽位

- `.skill-icon-box` 保留 90x90 稳定尺寸和定位上下文，移除普通状态下的背景、边框、圆角和阴影。
- 锁定技能可以保留独立的锁定占位表达，但不得形成比图标自身更大的圆角底框。
- `.passive-talent-card__icon` 保留 48x48 固定尺寸，移除背景、边框、圆角、阴影和裁切。
- `.status-square` 与 `.status-square__icon` 移除槽位背景和额外圆角；状态语义边框由 `StatusSemanticFrame` 单独承担。
- 冷却、GCD、倒计时和叠层数字继续渲染。冷却与 GCD 遮罩使用与图标自身圆角块面相匹配的内缩裁切，不依赖槽位背景填满透明角。
- 图标图片使用完整画布比例显示，不新增会遮挡主体的装饰层。

## 状态语义框

- 按用户选择保留完整状态语义框：玩家增益为绿色、玩家减益为红色、团队状态为金色或橙色、中性状态为灰色。
- 语义框不是图标槽背景，不承载职业或来源信息。
- 语义框保持小尺寸可见，但不得叠加额外圆角底色。
- 叠层数字与倒计时遮罩继续位于语义框上方。

## 敌人血条框线

### 悬停态

- 当前 3px 橙黄悬停视觉改为 6px 内描边。
- 外部宽高、网格位置和相邻敌人格位间距不变。
- 内描边不触发元素重排，不改变基础威胁色框的几何尺寸。

### 选中动态框

- 保留威胁色基础层，并将白色动态间断线作为选中主信号。
- 动态框视觉厚度由 3px 增至 6px。
- SVG 矩形路径同步向内缩进半个描边宽度，确保 6px 描边全部落在敌人血条内部，不向相邻格位扩张。
- 虚线节奏按新线宽调整，保持明显流动而非形成连续白框。

### 内部内容安全区

- 标题、血量、目标提示和施法条技能名与新 6px 内框保持清晰间距。
- 优先通过标题区和施法条的水平内边距建立安全区。
- 只有在桌面和窄视口截图显示文字仍被压迫时，才小幅调整字号或行高；不得用放大字号造成截断。
- 施法条高度和敌人格位高度默认保持不变。

## 组件与数据流

- 图标资源 URL 与工作簿映射保持不变，运行时数据加载流程不变。
- `SkillBar` 可移除只为角标传入的 `classId` 属性，避免保留无效接口。
- `StatusBadge` 继续根据状态语义渲染 `StatusSemanticFrame`，但不再消费来源字段进行视觉展示。
- `IconGrammarLegend` 删除来源形状分支；教程步骤和测试同步调整，避免讲解已经移除的规则。
- 敌人框只调整 `EnemyRaidFrameItem` 的选中 SVG 几何和对应 CSS，不改变选择逻辑。

## 测试策略

### 自动化回归

- 资产测试验证 53 个熊 T SVG 均包含 `data-icon-style="warrior-block"` 和实心核心层。
- 资产测试验证 SVG 不包含旧内部框、四角标记和底部横台标记。
- `SkillBar`、`PassiveTalentPanel`、`StatusBadge` 测试验证不再渲染 `data-status-source`、战旗或盾牌角标。
- CSS 测试验证技能、天赋、状态图标槽没有背景、边框、圆角和阴影。
- 状态测试继续验证绿色、红色、金色语义框存在。
- 敌人框测试验证悬停内描边和动态框线宽为 6px，并验证选中 SVG 路径内缩。

### 可视化验收

- 桌面战斗界面检查 8 个已装配熊 T 技能的主体区分度、冷却遮罩和数字无遮挡。
- 构筑界面检查 21 个天赋图标无角标、无槽位底框且排列稳定。
- 战斗状态与衍生状态检查语义框保留、职业角标消失、叠层数字可读。
- 敌人框分别检查普通、悬停、选中和施法状态，确认 6px 框线只向内生长且文字不贴边。
- 在桌面和窄视口检查无新增横向溢出或组件重叠。

## 完成标准

- 53 个熊 T 图标全部符合双色实心块面规则且无旧装饰框与底台。
- 战斗、构筑、状态和教程中不再出现职业来源战旗或盾牌角标。
- 图标紧邻槽位不再显示小背景圆角矩形，状态语义边框仍完整工作。
- 敌人悬停框和白色动态虚线框均以 6px 向内呈现，内部文字和施法名保持清晰。
- 定向测试、完整测试、Lint、构建、策划数据校验和视觉验收全部通过。
