# 熊T WF6 防御循环再平衡设计

## 目标

在不复制战士T“无视苦痛”的前提下，为熊T增加禁疗环境下的伤害平滑选择，并提升铁鬃、树皮术和基础仇恨循环，使熊T在WF6从当前0%通过率进入可评测区间。

## 主动技能

- 痛击：基础伤害10，成功释放获得10怒，冷却9000ms，仇恨倍率5。
- 月火术：冷却15000ms；释放时立即造成5点伤害，随后在3/6/9/12秒各造成5点伤害，总伤害25；每次伤害使用5倍仇恨，删除额外即时仇恨。
- 横扫：伤害8，仇恨倍率5，继续只有公共GCD。
- 铁鬃：默认每层20%物理减伤，最多3层。同一铁鬃来源线性相加；铁鬃与厚皮、树皮术、月下坚守等其他减伤来源使用乘法叠加。
- 树皮术：冷却30000ms，持续10000ms，30%全伤害减伤。
- 愈合：即时固定治疗25点，随后3跳各固定治疗5点，总治疗40点；禁疗仍逐次作用于即时与每跳治疗。

## 被动天赋

- 厚皮：10%常驻物理减伤。
- 月下坚守：月火术存在时10%全伤害减伤。
- 自然坚韧替换为疼痛豁免，稳定ID改为`druid_bear_t_pain_immunity`，Tier和uiOrder沿用原位置，消耗3点。装备后痛击伤害降低30%、不再产生基础怒气；每个实际命中的目标给予5点全伤害吸收，单次最多20点。专属护盾持续9000ms，同源护盾累加但总量上限20点，并在新痛击命中时刷新持续时间。与痛苦之怒使用互斥组`druid_bear_t_thrash_choice`。
- 野性复原替换为水火不侵，稳定ID改为`druid_bear_t_water_fire_immunity`，Tier和uiOrder沿用原位置，消耗4点。装备后铁鬃改为每层15%物理减伤和8%魔法减伤，最多4层。与厚皮使用互斥组`druid_bear_t_ironfur_choice`。

## 数据与运行时边界

- 通过稳定ID定点修改`public/designer-data/player_build.xlsx`，不运行批量工作簿生成器。
- 新天赋沿用被替换天赋的图标素材位置，但使用新的图标ID、状态ID和逻辑ID，避免旧语义残留。
- 构筑生成器继续使用通用`exclusiveGroup`约束，不增加熊T专用硬编码。
- WF6评测先使用当前关卡、敌人和AI，不修改关卡数据；如仍为0%，分别记录生存、仇恨、禁疗和资源断点，不用全局数值继续硬抬。

## 验证标准

- 策划表定义、运行时伤害/治疗/怒气/护盾/减伤叠加均有聚焦测试。
- 两个竞争组在默认构筑和自动生成构筑中不能同时出现。
- `npm test`、`npm run validate:designer-data`、`npm run lint`、`npm run build`和`git diff --check`通过。
- 输出WF6熊T专项固定策略和学习策略报告，并与修改前0%基线对比。
