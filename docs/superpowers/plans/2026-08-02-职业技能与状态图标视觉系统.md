# 职业技能与状态图标视觉系统 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不改写正式美术资产的前提下，为战士 T 与熊 T 落地“语义外框 + 职业纹章挂饰 + 主动/被动来源形状 + 叠层/计时”状态图标语法，并在首次进入战斗时提供可重看的三步教程。

**Architecture:** `StatusEffect` 保存明确的来源与语义数据，状态创建层从技能/天赋定义解析来源，UI 层通过纯函数把数据映射为外框、挂饰和叠层展示。职业纹章注册表独立于已发布职业注册表，预留六个职业的轮廓与高对比颜色；教程复用同一套实际组件。正式主体美术、策划工作簿和 `public/` 映射留在用户明确批准后的独立批次。

**Tech Stack:** TypeScript 6、React 19、Lucide React、Vitest、JSDOM、CSS

```ts
// statusIconPresentation.ts
export type StatusSemantic = 'beneficial' | 'harmful' | 'party-beneficial' | 'party-harmful' | 'neutral'
export type StatusSourceShape = 'banner' | 'oval-shield'

export function getStatusSemantic(status: Pick<StatusEffect, 'kind' | 'tone'>): StatusSemantic {
  if (status.kind === 'playerBuff') return 'beneficial'
  if (status.kind === 'enemyBuff' || status.kind === 'playerDebuff') return 'harmful'
  if (status.kind === 'partyDebuff') return 'party-harmful'
  return status.tone === 'buff' ? 'party-beneficial' : status.tone === 'danger' ? 'harmful' : 'neutral'
}

export function getSourceShape(sourceKind?: StatusSourceKind): StatusSourceShape | null {
  return sourceKind === 'activeSkill' ? 'banner' : sourceKind === 'passiveTalent' ? 'oval-shield' : null
}

export function clampVisibleStacks(status: Pick<StatusEffect, 'stacks' | 'maxStacks'>) {
  if (!status.maxStacks || status.maxStacks <= 1 || !status.stacks || status.stacks <= 1) return null
  return Math.min(status.stacks, status.maxStacks)
}
```
