# 熊 T 主线 Delta 数值平衡实施计划

> **供执行代理使用：** 按任务顺序执行，并使用复选框（`- [ ]`）跟踪进度。

**目标：** 补齐熊 T 主线解锁快照，将 Delta 分析扩展到主动技能和挑战数据，生成章节级报告，依据证据调整熊 T 异常项，并打开已验证演示。

**架构：** 主线解锁数据保留在 `stage_content.xlsx`，将主线与挑战工作簿载入统一分析目录，并在现有被动变体旁增加主动技能存在性对比。使用按范围命名的报告，避免长时分析互相覆盖。

**技术栈：** TypeScript、Vitest、Node.js、XLSX、现有平衡模拟与报告流水线、Vite。
