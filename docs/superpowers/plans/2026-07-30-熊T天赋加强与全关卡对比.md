# 熊 T 天赋加强与全关卡双职业评测实施计划

> **供执行代理使用：** 按任务顺序执行，并使用复选框（`- [ ]`）跟踪进度。

**目标：** 加强七项熊 T 天赋、修正未选中敌人血条双框，并用完整预算生成挑战 1~9、WF1~6、ZA1~6 的熊 T/战士 T 对比基线。

**架构：** `player_build.xlsx` 保持为策划数值源，定向维护脚本只更新指定天赋行；运行时继续通过现有 `talentLogicId` 读取数值，仅在玩家承受物理伤害时把厚皮与铁鬃合并成同一加法减伤段。平衡分析沿用现有分析器，新增纯汇总器把挑战和主线 JSON 合并成一份 21 关双职业 Markdown/JSON 报告。

**技术栈：** TypeScript 6、Vitest、React 19、CSS、Node.js、SheetJS/xlsx、现有确定性平衡模拟器。

- [ ] **步骤 4：将厚皮并入铁鬃加法减伤段**

修改 `src/game/encounter/encounterFactory.ts`，让承伤入口使用一个组合函数：

```ts
function getBearCombinedPhysicalMitigationMultiplier(
  player: PlayerState,
  passiveTalentIds: PassiveTalentId[],
  damageType: EnemySkillDamageType,
) {
  const mitigationReduction = getPlayerMitigationReduction(player, damageType)
  const thickHideReduction = damageType === 'physical'
    ? getPassiveModifiers(passiveTalentIds).bearPhysicalDamageReduction
    : 0
  return 1 - Math.min(0.95, mitigationReduction + thickHideReduction)
}
```

保留铁鬃余韵与铁鬃自身当前的同段加法，删除随后再次乘以厚皮的旧调用，确保树皮术等 `playerDamageTakenMultiplier` 仍在下一段相乘。
