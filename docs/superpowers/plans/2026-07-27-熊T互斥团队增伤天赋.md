# 熊 T 互斥团队增伤天赋实施计划

> **供执行代理使用：** 按任务顺序执行，并使用复选框（`- [ ]`）跟踪进度。

**目标：** 将三项熊 T Tier 1 天赋改为互斥团队输出选项，并针对 WF6 与挑战 3~6 调整熊 T。

**架构：** 策划定义继续保留在 `player_build.xlsx`。静态天赋修正处理野性印记，战斗伤害结算处理铁棘，伤害源构建处理自然鼓舞；构筑规范化作为 UI 与自动构筑生成共同复用的唯一合法性边界。

**技术栈：** TypeScript、Vitest、SheetJS/XLSX、现有战斗模拟器与平衡报告流水线。
