# 挑战与西部荒野前段关卡数值平衡实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不修改职业与全局怪物数值的前提下，通过定点调整挑战1~9和WF1~3的敌人编成、开场时序与站位，使战士T和熊T的固定策略AI结果尽量进入`docs/关卡数值期望.md`规定区间。

**Architecture:** 策划表继续是唯一运行数据源；新增一个只认`stageId + spawnId`的定向写表脚本和一组工作簿契约测试，禁止整表生成。候选选择先用现有确定性模拟器的quick预算筛选，再用normal预算收敛，最后对重点挑战使用full预算复核；每轮仅保留一个可解释的变量族。

**Tech Stack:** Node.js ESM、SheetJS/xlsx、TypeScript 6、Vitest、现有固定策略AI平衡模拟器、Markdown/JSON报告。

---

## 文件职责

- `src/game/balance/analyzeBalanceTemplate.test.ts`：读取脚本模板时统一行尾，保证Windows和Linux断言一致。
- `src/game/balance/stageEncounterBalanceContract.test.ts`：锁定12关允许怪物边界、最终spawn值、最多两名替换和负伤变体规则。
- `scripts/applyStageEncounterBalance.mjs`：读取候选清单，按`workbook + sheetName + stageId + spawnId`唯一键写入最终选择，不匹配或重复即停止。
- `reports/balance/挑战与西部荒野前段关卡最终候选-2026-08-02.json`：保存quick筛选后选中的结构化更新清单，供写表器和报告共同使用。
- `public/designer-data/challenge_encounter_balance.xlsx`：仅修改挑战1~9的`敌人布置`目标行。
- `public/designer-data/encounter_balance.xlsx`：仅修改WF1~3的`敌人布置`目标行。
- `reports/balance/挑战1至9与西部荒野1至3数值平衡报告-2026-08-02.md`：记录基线、候选理由、最终结果、未达标项和结构性原因。
- `docs/玩家坦克职业扩展开发交接.md`：追加本轮关卡基线、复测入口和后续人工验证事项。
