# 熊 T WF6 防御重平衡实施计划

> **供执行代理使用：** 按任务顺序执行，并使用复选框（`- [ ]`）跟踪进度。

**目标：** 实现已确认的熊 T 主动技能、减伤、治疗和互斥天赋改动，并在不修改关卡的前提下测量其对 WF6 的影响。

**架构：** 策划数值保留在 `player_build.xlsx`，只新增疼痛豁免与水火不侵所需的运行时状态，并复用通用天赋竞争组流水线。减伤计算必须在铁鬃来源内部线性汇总层数，再与其他独立减伤来源乘法叠加。

**技术栈：** TypeScript、Vitest、SheetJS/XLSX 策划工作簿、现有平衡模拟器。
